# 🗣️ Voice-Based Government Scheme Assistant using AI

Discover the right government scheme, faster — powered by AI.

## 📖 About

Millions of eligible citizens miss out on government welfare schemes simply because they don't know these schemes exist or don't understand if they qualify. This project solves that problem with an intelligent assistant that listens, reads, and understands — turning a user's profile or uploaded documents into personalized, easy-to-understand scheme recommendations.

## ✨ Features

- 🔐 User registration, login & profile management
- 🎙️ Voice, text, and document input with OCR extraction
- 🤖 AI-based eligibility analysis and scheme recommendations
- 📋 Detailed scheme information — benefits and required documents
- 🔒 Secure storage of user data and recommendation history

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| 🖥️ Frontend / Backend | React.js, Spring Boot, FastAPI |
| 🧠 AI / NLP | LangGraph, Gemini, Whisper, OCR |
| 🗄️ Database | PostgreSQL |
| 📡 Data Collection | PIB RSS, Web Scraping |
