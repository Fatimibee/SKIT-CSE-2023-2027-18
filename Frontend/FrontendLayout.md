## 2. Planned Future Frontend Pages

Based on the project workflow, detailed system architecture (LangGraph AI orchestration, OCR pipeline, voice delivery), and upcoming features, the following pages need to be built:

### Core User Experience Pages
* **`SchemeRecommendationPage`** (`SchemeRecommendationPage.jsx`)
  * Personalized scheme discovery portal listing eligible government schemes. Features explainable decision tags (*Why Eligible*, *Confidence Score*, *Matched Criteria*, and *Missing Eligibility Requirements*).
* **`SchemeDetailsPage`** (`SchemeDetailsPage.jsx`)
  * Dedicated view for a selected government scheme detailing comprehensive scheme objectives, benefit amounts, required documents, eligibility rules, and official links.
* **`DocumentVerificationPage`** (`DocumentUploadPage.jsx` / `DocumentVerificationPage.jsx`)
  * Interactive page for document upload (Aadhaar, income certificate, caste certificate). Displays real-time local OCR (PaddleOCR) scanning, spatial layout coordinate parsing results, and extracted profile parameters.

  * Multi-lingual voice-first interface supporting Speech-to-Text (Whisper STT) and Text-to-Speech (TTS) response delivery for hands-free query interaction and conversational eligibility checking.

### User Management & History Pages
* **`UserProfilePage`** (`UserProfilePage.jsx`)
  * User profile management page for inputting personal attributes (age, occupation, income, state, category) and managing saved credentials/verified document data.
* **`RecommendationHistoryPage`** (`RecommendationHistoryPage.jsx`)

### Automation & Application Pages
* **`FormAutoFillPage`** (`FormAutoFillPage.jsx`)

### System & Administrative Pages
* **`AdminDashboardPage`** (`AdminDashboardPage.jsx` / `SchemeManagementPage.jsx`)
  * Administrative management portal for managing the scheme repository database, triggering real-time web scraping (`india.gov.in`) and PIB RSS feed updates, and monitoring backend system analytics.

  * User preferences page for selecting multi-lingual voice/text output languages, adjusting speech synthesis parameters, and configuring notifications.
* **`HelpSupportPage`** (`HelpSupportPage.jsx`)
